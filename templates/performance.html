🎓 Understanding Model Performance

Accuracy: percentage of test examples classified correctly.

Precision: when the model predicts a category, how often that prediction is correct.

Recall: how well the model finds examples belonging to each category.

F1 Score: a balance between precision and recall.

Confusion Matrix: shows which categories the model confuses with each other.

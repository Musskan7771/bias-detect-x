🎓 Project & Viva Guide

Problem Statement

People can make decisions using mental shortcuts that introduce systematic bias. This project detects language patterns associated with common cognitive biases.

Objectives

Classify text, show confidence, explain the prediction, provide practical tips, and demonstrate an end-to-end ML workflow.

Methodology

Collect labeled examples → TF-IDF vectorization → Logistic Regression → holdout evaluation → web prediction.

Technologies

Python, Flask, pandas, scikit-learn, joblib, HTML, CSS and JavaScript.

Future Scope

More training data, transformer-based models, multilingual support, human feedback and calibrated confidence.

Important Note

This is an educational ML prototype, not a psychological diagnostic system.

🕘 History

Educational prototype only. A prediction is not a psychological diagnosis.
